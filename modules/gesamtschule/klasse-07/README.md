# Gesamtschule, Klasse 7

**Geräte:** In Klasse 7 gibt es keine Schul-iPads (iPads erst ab Klasse 8).

Module für diese Klasse planen deshalb:
- Papier zuerst: Planen und Schreiben auf gedruckten Bögen
- Upload über ein Gerät zu Hause (Elternteil) oder über das Gerät der Lehrkraft
- Alles am Bildschirm muss auf einem Smartphone mit 375 px Breite funktionieren.
